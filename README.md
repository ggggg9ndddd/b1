# محلل المحتوى الذكي

موقع عربي متجاوب لتحليل المحتوى مباشرة في المتصفح.

## الملفات
- `index.html`
- `style.css`
- `script.js`

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع الملفات الثلاثة إلى المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch.
5. اختر فرع `main` والمجلد `/root` ثم Save.

## ملاحظة
النسخة الحالية تستخدم تحليلًا محليًا داخل JavaScript، لذلك تعمل بدون API وبدون خادم. لربطها بخدمة ذكاء اصطناعي حقيقية مثل OpenAI يجب استخدام Backend أو Serverless Function لحماية مفتاح API وعدم وضعه داخل `script.js`.
